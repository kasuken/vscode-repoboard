# Switch projects from anywhere

| Type | Finds |
| --- | --- |
| `chkweb` | **checkout-web**: fuzzy on names |
| `apple-pay` | repos on the branch `feature/apple-pay` |
| `#acme` | every repo tagged *acme* |
| `#acme pay` | tag and text together |

In the list:

- **Enter** opens the repo, following your *Open in new window* setting.
- The **window** button opens it in a new window.
- The **terminal** button opens a terminal in it.
- The **pin** button keeps it at the top.

Prefer another key? Search for `repoBoard.switch` in **Keyboard Shortcuts**.
